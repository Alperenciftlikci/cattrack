# Mochi — Cat Care AI Website

Static website for the Mochi iOS app. Deployed via GitHub Pages.

## Files

- `index.html` — Landing page
- `privacy-policy.html` — Detailed local-first privacy policy
- `terms.html` — Redirects to Apple Standard EULA

## Local preview

```bash
python3 -m http.server 8000
# Open http://localhost:8000
```

## Deploy

Push to `main` branch — GitHub Pages serves from root automatically.
